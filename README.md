# Dayardan — ExamTrainer

> *Sunrise, Parabellum.*

**Dayardan** is a full-stack exam preparation platform that lets students practice subject-based multiple-choice exams, review their history, and receive AI-powered feedback on their mistakes. Administrators can manage subjects and questions through a built-in admin panel.

## Features

### For Students
- **Subject Selection** — Browse and select from available exam subjects.
- **Interactive Exam Mode** — Navigate multi-page question cards with instant answer tracking and a progress counter. Up to 30 randomly selected questions per session.
- **Instant Results** — See your score, pass/fail status, and a full breakdown right after submission.
- **Attempt History** — View all past exam attempts with dates and scores (requires login).
- **Attempt Detail Review** — Drill into any past attempt to see your answers vs. the correct ones.
- **AI-Powered Feedback** — Get a personalized mistake analysis and a study roadmap generated by an LLM (Groq / Llama 4), rendered as formatted Markdown. Results are cached per attempt.

### For Administrators
- **Subject Management** — Add, edit, and delete exam subjects directly from the UI.
- **Question Management** — Create, edit, delete, and paginate questions per subject via a dedicated admin panel.
- **Answer Option Image Upload** — Upload images for individual answer options via the admin panel.

### Platform
- **JWT Authentication** — Secure, stateless auth with role-based access control (Admin / User).
- **Multilingual UI** — Full localization in **English**, **Russian (Русский)**, and **Kyrgyz (Кыргызча)**.
- **Responsive Design** — Works across desktop and mobile screen sizes.

## Getting Started

### Prerequisites

- [.NET 9 SDK](https://dotnet.microsoft.com/download/dotnet/9)
- [Node.js 20+](https://nodejs.org/) and npm
- [SQL Server](https://www.microsoft.com/en-us/sql-server) (LocalDB, Express, or a hosted instance)
- A [Groq API key](https://console.groq.com/) for AI feedback (optional — the rest of the app works without it)

---

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/ExamTrainer.git
cd ExamTrainer
```

---

### 2. Backend Setup (API)

#### a. Configure User Secrets (recommended for local dev)

Navigate to the `api/` directory and use the .NET Secret Manager to store sensitive values locally (they are **not** committed to source control):

```bash
cd api
dotnet user-secrets set "ConnectionStrings:DefaultConnection" "Server=localhost;Database=ExamTrainerDb;Trusted_Connection=True;TrustServerCertificate=True;"
dotnet user-secrets set "JWT:Issuer" "http://localhost:5000"
dotnet user-secrets set "JWT:Audience" "http://localhost:5000"
dotnet user-secrets set "JWT:SigningKey" "your-super-secret-signing-key-at-least-32-chars"
dotnet user-secrets set "Groq:ApiKey" "gsk_your_groq_api_key"
```

Alternatively, you can fill in `appsettings.Development.json` directly (do **not** commit real secrets).

#### b. Apply Database Migrations

```bash
dotnet ef database update
```

This creates the database schema and seeds a default **admin** user automatically on first run.

#### c. Run the API

```bash
dotnet run
```

The API will start at `https://localhost:7xxx` / `http://localhost:5xxx` (port shown in the terminal). Swagger UI is available at `/swagger` in Development mode.

---

### 3. Frontend Setup (Client)

#### a. Configure the API URL

Copy the example env file and point it to your running API:

```bash
cd client
cp .env .env.local
```

Edit `.env.local`:
```env
VITE_API_URL=http://localhost:5000
```

#### b. Install Dependencies

```bash
npm install
```

#### c. Run the Dev Server

```bash
npm run dev
```

The app will be available at `http://localhost:5173`.

## Running in Production

### Docker (API)

A multi-stage `Dockerfile` is included in `api/`. Build and run the container:

```bash
cd api
docker build -t dayardan-api .
docker run -p 8080:8080 \
  -e ConnectionStrings__DefaultConnection="<your-connection-string>" \
  -e JWT__Issuer="https://yourdomain.com" \
  -e JWT__Audience="https://yourdomain.com" \
  -e JWT__SigningKey="<your-signing-key>" \
  -e Groq__ApiKey="<your-groq-key>" \
  dayardan-api
```

> **Note:** The API serves the compiled React SPA from its `wwwroot/` folder in production, so a single container can serve both the API and the frontend. `appsettings.Production.json` is excluded via `.gitignore`.

### Frontend Build

Build the production bundle and copy it to the API's `wwwroot/`:

```bash
cd client
npm run build
# Copy the dist/ contents into api/wwwroot/
```

The ASP.NET app is configured with `MapFallbackToFile("index.html")` to support client-side routing.

## API Overview

All endpoints are prefixed with `/api`. Authenticated routes require a `Bearer <token>` header.

| Method | Endpoint | Auth | Description |
|---|---|---|---|
| `POST` | `/api/account/register` | Public | Register a new user |
| `POST` | `/api/account/login` | Public | Login and receive JWT |
| `GET` | `/api/subjects` | Public | List all subjects |
| `GET` | `/api/subjects/{id}` | Public | Get a single subject |
| `POST` | `/api/subjects` | Admin | Create a subject |
| `PATCH` | `/api/subjects/{id}` | Admin | Update a subject |
| `DELETE` | `/api/subjects/{id}` | Admin | Delete a subject |
| `GET` | `/api/subjects/{subjectId}/questions` | Public | Get paginated questions for a subject |
| `POST` | `/api/subjects/{subjectId}/questions` | Admin | Create a question |
| `PATCH` | `/api/subjects/{subjectId}/questions/{id}` | Admin | Update a question |
| `DELETE` | `/api/subjects/{subjectId}/questions/{id}` | Admin | Delete a question |
| `GET` | `/api/exam/start/{subjectId}` | Public | Load a randomised set of questions for an exam |
| `POST` | `/api/exam/submit` | Public | Submit exam answers and receive a score |
| `GET` | `/api/exam/history` | Auth | Get the current user's attempt history |
| `GET` | `/api/exam/attempts/{id}` | Auth | Get details of a specific attempt |
| `GET` | `/api/exam/attempts/{id}/feedback` | Auth | Get (or generate) AI feedback for an attempt |
| `POST` | `/api/upload/answer-option-image` | Admin | Upload an image for an answer option |
| `DELETE` | `/api/upload/answer-option-image` | Admin | Delete an answer option image |

Full interactive documentation is available via Swagger at `/swagger` (Development only).

## Localization

The UI supports **three languages**, selectable at runtime via a language switcher in the navbar:

| Code | Language |
|---|---|
| `en` | English |
| `ru` | Русский (Russian) |
| `ky` | Кыргызча (Kyrgyz) |

Translations live in `client/src/i18n/strings.ts`. To add a new language, add a new key to the `LanguageCode` type and provide a full translation object.
